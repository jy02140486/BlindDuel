> 状态：方案草稿（待 GPT 评审） | 创建：2026-10-05

## §1 设计决策总览（已确认）

| # | 决策 | 理由 |
|---|------|------|
| ① | **Guard 不能挡 projectile** | ProjectileContactResolver 只检查 dodge 跳过，不加 guard 检查。反制手段只有 dodge（无敌帧覆盖）或 cut（slash 打掉） |
| ② | **Cut 在 v1 范围**（核心价值） | AI 需要预测 projectile 未来位置 + 计时自己 slash startup，让 weaponbox 覆盖轨迹点。成功时给移动加速 buff（架构冲突可 skip） |
| ③ | **Action commitment 风险接受**（方案 A） | AI 在 attack/guard/dodge 动画中不重新决策，飞刀在 committed 窗口命中就命中了——现有架构不动 |
| ④ | **新增 `throwActive: true` 标记**，不蹭 `attackActive` | attackActive 会触发 CombatCharacter.js:529 的 miss outcome 污染 + 574 的 interrupted + AIKnowledgeRegistry 无 weaponbox 帧 return null 根本扫不出来 |
| ⑤ | **投掷物威胁和 attack/defense/positioning 同池竞争** | 靠 dodge/cut 分数本身（timeToImpact 窗口内自然高）胜过 positioning |
| ⑥ | **Phase 粒度：windup + 独立 threat** | opp 进 throw 状态 → `oppPhase="throw_windup"`（preemptive dodge 窗口）；release 后 → 查 ProjectileManager 拿精确位置，但 **不覆盖 oppPhase**（opp 可能已回 idle/guard）。投掷物威胁作为 Situation 独立字段 `activeProjectileThreats[]` 并行存在 |
| ⑦ | **ProjectileDefs + StateGraph throw state 联合扫描** | ProjectileDefs 提供静态属性（cuttable/speed/damage），StateGraph throw state 提供时序属性（throwReleaseFrame → 算 startupMs） |

## §2 架构总览

### 2.1 数据流

```
ProjectileDefs（外部化数据源）
  ├─ ThrowComponent.release() 读 config
  └─ AIKnowledgeRegistry.#scanThrowState 读静态属性
StateGraph JSON
  └─ throw state: { throwActive, projectileType, throwReleaseFrame }
      └─ AIKnowledgeRegistry 读时序属性 → throwProfile[]

AIKnowledgeRegistry (静态层)
  ├─ attacks[]    // 已有
  ├─ dodges[]     // 已有
  ├─ guards[]      // 已有
  └─ throws[]      // 新增：throwProfile[]

AIController (动态层)
  #buildSituation()
    ├─ 已有：oppPhase/oppThreat (attack 链路)
    ├─ 新增分支：oppDef.throwActive → 查 opponentKB.throws
    │     → oppPhase="throw_windup"
    └─ 新增：查询 ProjectileManager
          → activeProjectileThreats[]  (动态位置/timeToImpact/cuttable)

#makeDecision()
  候选池（同池竞争）：
    attack: swing/thrust/dash...
    guard: guard_low/guard_high/parry...
    dodge: backstep/sidehop...
    approach/hold/retreat...
    ──────────────────────────
    从已有 kbProfile.dodges 里选 timing 最优的 dodge（因 projectile threat 触发）
    从已有 kbProfile.attacks 里选 timing 最优的 slash（因 projectile cut 触发，仅 cuttable=true）

  → 排序 → 最高分执行

  关键设计：
  - **不发明新 state**：projectile defense 触发的是已有 dodge/slash action
  - **评分和执行同一个 action**：#scoreProjectileDefense 内部就选好 bestDodge/bestSlash，返回 {score, action}，candidate 直接存，不再二次筛选
```

### 2.2 两层模型（静态 + 动态）

```
静态层（ProjectileTypeProfile — 放进 AIKnowledgeRegistry）
  typeId: "dagger" | "rock" | "spear"
  speed: 世界空间速度
  arcHeight: 抛物线高度
  cuttable: boolean
  damage: number
  lifetimeMs: number

动态层（Situation.activeProjectileThreats[] — #buildSituation 每 tick 从 ProjectileManager 查）
  projectile: Projectile 实例引用
  profile: 引用静态层 ProjectileTypeProfile
  position: {x, y} — 当前 simPos
  velocity: {x, y}
  estimatedTimeToCurrentPosition: 简化 TTI — 假设 self 停在当前位置不移动。direction check 已前置过滤（projectile 远离时不生成 threat）
  distanceToSelf: 与 self XY 平面距离
  isInFlight: boolean (spawn 后)
```

### 4.2 StateGraph throw state 新标记

```json
{
  "name": "throw",
  "clip": "longswordman_throw",
  "throwActive": true,
  "projectileType": "dagger",
  "throwReleaseFrame": 3,
  "command": "dagger",
  "transition": { "command": "idle" }
```

三个新字段含义：
| 字段 | 类型 | AI 侧消费 |
|------|------|----------|
| `throwActive` | boolean | AIKnowledgeRegistry 判断是否扫描 throw 状态；#buildSituation 判断 opp 是否在扔东西 |
| `projectileType` | string | 查 ProjectileDefs 拿到 cuttable/speed/damage |
| `throwReleaseFrame` | number | 从 atlasData 累加该帧之前的 duration → startupMs（windup 窗口长度）。**语义约定**：`for (let i=0; i<throwReleaseFrame; i++)` = 前 N 帧播完后 release，即 release 帧 **开始** 时触发 |

**为什么不用 attackActive**：
- CombatCharacter.js:529 会进 attackActive 分支 → `_lastAttackHadHit=false` + 存 null 的 `_currentAttackInstanceId`
- CombatCharacter.js:574 退 attackActive → 调 `onCombatResult({outcome:"miss"})` → 污染 CombatMemory（把 throw 记成失败攻击）
- CombatSystem.js:166 throw 状态被击中 → 产生 `interrupted` outcome → 语义不对
- AIKnowledgeRegistry.#scanAttackState 无 weaponbox 帧 → 直接 return null → 白加

### 4.3 AIKnowledgeRegistry 新增 throw 扫描

```js
static #scanThrowState(stateName, stateDef, clipDef, warnings) {
    const projectileType = stateDef.projectileType;
    const throwReleaseFrame = stateDef.throwReleaseFrame ?? 0;
    const def = ProjectileDefs[projectileType];

    // cross-reference validation：ProjectileDefs 是 projectile gameplay 属性的唯一真相
    if (!def) {
        warnings.push(`State ${stateName} references unknown projectileType "${projectileType}" in ProjectileDefs — skipping throw scan`);
        return null;
    }

    // 从 atlasData 算 startupMs（release 帧之前所有帧 duration 累加）
    const atlasFrames = this.#extractAtlasFrames(clipDef.atlasData, stateName, warnings);
    let startupMs = 0;
    for (let i = 0; i < throwReleaseFrame && i < atlasFrames.length; i++) {
        startupMs += atlasFrames[i]?.durationMs ?? 100;
    }
    const totalMs = atlasFrames.reduce((s, f) => s + (f.durationMs ?? 100), 0);

    return {
        stateName,
        projectileType,
        cuttable: def?.cuttable ?? true,
        damage: def?.damage ?? 1,
        speed: def?.speed ?? 14,
        timing: {
            startupMs,       // windup 窗口长度
            totalMs,         // 整个 throw 动画时长
            releaseFrame: throwReleaseFrame
        }
    };
}

// #scanCharacter 里新增：
const throwProfiles = [];
for (const [stateName, stateDef] of Object.entries(states)) {
    if (stateDef.throwActive === true) {
        const clipDef = clips[stateDef.clip];
        if (clipDef) {
            const profile = this.#scanThrowState(stateName, stateDef, clipDef, warnings);
            if (profile) throwProfiles.push(profile);
        }
    }
}
// 塞进 return 对象：throws: throwProfiles
```

### 4.5 #buildSituation 新增 throw 感知分支

在现有 attack phase 检测之后加 throw 检测：

```js
// --- 已有：attack phase 检测 ---
if (oppDef?.attackActive === true && this.opponentKB) {
    // ... 现有代码 ...
}

// --- 新增：throw phase 检测 ---
if (oppPhase === "none" && oppDef?.throwActive === true && this.opponentKB?.throws) {
    const oppThrowProfile = this.opponentKB.throws.find(t => t.stateName === oppState);
    if (oppThrowProfile) {
        oppPhase = "throw_windup";
        oppThreat = this.tuning.threatPerPhase.throw_windup ?? 0.5;
    }
}

// --- 新增：查询 in-flight projectiles ---
// 注意：activeProjectileThreats 是 Situation 独立字段，不影响 oppPhase。
// oppPhase 只反映 opponent 当前的 action phase（如 attack/windup/recovery）。
// 对手扔完飞刀后可能已回 idle/guard，但 threat 仍存在。
const activeProjectileThreats = [];
if (this.projectileManager && this.opponent) {
    const selfX = this.character.root.position.x;
    for (const p of this.projectileManager.getActiveProjectiles()) {
        if (p.ownerId !== this.opponent.id) continue;
        if (p.isDestroyed) continue;

        // === direction check：projectile 必须朝 self 飞来 ===
        // self 在 projectile 右侧 → projectile velocity.x 应为负；self 在左 → 应为正
        const dirX = selfX - p.simPos.x;           // >0 = self 在右边
        const velocityTowardsSelf = Math.sign(dirX) === Math.sign(p.velocity.x);
        if (!velocityTowardsSelf) continue;  // 远离我，不是威胁

        // === 估算到达时间 ===
        // 简化 TTI：假设 self 停在当前位置（v1 简化假设）
        const distanceToSelf = Math.abs(dirX);
        const vx = Math.abs(p.velocity.x);
        const estTimeToCurrentPositionMs = vx > 0 ? (distanceToSelf / vx) * 1000 : 9999;

        activeProjectileThreats.push({
            projectile: p,
            profile: ProjectileDefs[p.projectileType] ?? null,
            position: { x: p.simPos.x, y: p.simPos.y },
            velocity: { x: p.velocity.x, y: p.velocity.y },
            distanceToSelf,
            estTimeToCurrentPositionMs,  // 命名明确是 stationary target 简化
            cuttable: p.cuttable,
        });
    }
}

// 独立 threat 字段存在时，叠加 oppThreat（但不改 oppPhase）
if (activeProjectileThreats.length > 0) {
    const maxUrgency = Math.max(...activeProjectileThreats.map(
        t => Math.max(0, 1 - t.estTimeToCurrentPositionMs / 1500)
    ));
    oppThreat = Math.max(oppThreat, maxUrgency * 0.8);
}
```

### 4.6 #scoreProjectileDefense（新评分方法）

**核心契约：直接返回 `{ score, action }`，action 就是选中的真实 dodge/slash。**
#makeDecision 不再二次筛选——评分选了谁就执行谁，保证 utility 体系的一致性。

```js
// === 入口：选最紧急 threat，同时评分 dodge 和 cut，各返回 {score, action} ===
#evaluateProjectileDefense(sit) {
    const threats = sit.activeProjectileThreats ?? [];
    if (threats.length === 0) return null;

    // 选最紧急 threat（先按 estTimeToCurrentPositionMs 排序取最小）
    const threat = threats.reduce((a, b) =>
        a.estTimeToCurrentPositionMs < b.estTimeToCurrentPositionMs ? a : b);

    const tti = threat.estTimeToCurrentPositionMs;
    const results = [];

    // --- dodge 分支：选 timing 最合适的 dodge action ---
    const bestDodge = this.#findBestDodgeForProjectile(tti, threat);
    if (bestDodge) {
        const dodgeScore = this.#scoreDodgeForProjectile(bestDodge, tti, threat);
        results.push({
            kind: "dodge",
            action: bestDodge,   // ← 评分选好的真实 dodge，执行时直接用
            score: dodgeScore,
            reason: "projectile",
            isProjectileDefense: true
        });
    }

    // --- cut 分支（仅 cuttable=true）：选 timing 最合适的 slash ---
    if (threat.cuttable) {
        const bestSlash = this.#findBestSlashForProjectile(tti, threat);
        if (bestSlash) {
            const cutScore = this.#scoreCutForProjectile(bestSlash, tti, threat);
            results.push({
                kind: "attack",
                action: bestSlash,   // ← 评分选好的真实 slash，执行时直接用
                score: cutScore,
                reason: "projectile_cut",
                isProjectileCut: true
            });
        }
    }

    return results;
}

// === findBestDodgeForProjectile：从 kbProfile.dodges 选 timing 最优的 dodge ===
#findBestDodgeForProjectile(tti, threat) {
    const dodges = this.kbProfile?.dodges ?? [];
    if (dodges.length === 0) return null;

    let bestDodge = null;
    let bestScore = -Infinity;

    for (const dodge of dodges) {
        const totalMs = dodge.timing.totalMs;
        // timeWindowFactor：tti 在 [totalMs, totalMs+300] 时满窗口
        let f;
        if (tti >= totalMs && tti <= totalMs + 300) f = 1.0;
        else if (tti < totalMs) f = Math.max(0, tti / totalMs);  // 太晚
        else f = Math.max(0, 1 - (tti - totalMs - 300) / 700);  // 太早
        if (f > bestScore) { bestScore = f; bestDodge = dodge; }
    }
    return bestDodge;
}

#scoreDodgeForProjectile(dodge, tti, threat) {
    const totalMs = dodge.timing.totalMs;
    let timeWindowFactor;
    if (tti >= totalMs && tti <= totalMs + 300) timeWindowFactor = 1.0;
    else if (tti < totalMs) timeWindowFactor = Math.max(0, tti / totalMs);
    else timeWindowFactor = Math.max(0, 1 - (tti - totalMs - 300) / 700);

    let score = this.tuning.projectileDefense.dodgeBase ?? 0.45;
    score *= timeWindowFactor;
    score *= this.combatPosture.defenseMultiplier;
    if (threat.distanceToSelf < 0.2) score *= 0.3;  // 已经飞过了
    return Math.max(0, Math.min(0.9, score));
}

// === findBestSlashForProjectile：从 kbProfile.attacks 里的 slash 选 timing 最优 ===
#findBestSlashForProjectile(tti, threat) {
    const slashAttacks = (this.kbProfile?.attacks ?? [])
        .filter(a => a.trajectory === "slash");
    if (slashAttacks.length === 0) return null;

    let bestSlash = null;
    let bestTimingScore = -Infinity;

    for (const slash of slashAttacks) {
        const activeStart = slash.timing.startupMs;
        const activeEnd = slash.timing.startupMs + slash.timing.activeMs;
        let timingAlignment;
        if (tti >= activeStart && tti <= activeEnd) timingAlignment = 1.0;  // 完美
        else if (tti < activeStart) timingAlignment = Math.max(0, 1 - (activeStart - tti) / activeStart);  // 太慢
        else timingAlignment = Math.max(0, 1 - (tti - activeEnd) / 500);  // 太快

        if (timingAlignment > bestTimingScore) {
            bestTimingScore = timingAlignment;
            bestSlash = slash;
        }
    }
    return bestTimingScore > 0 ? bestSlash : null;
}

#scoreCutForProjectile(slash, tti, threat) {
    const activeStart = slash.timing.startupMs;
    const activeEnd = slash.timing.startupMs + slash.timing.activeMs;
    let timingAlignment;
    if (tti >= activeStart && tti <= activeEnd) timingAlignment = 1.0;
    else if (tti < activeStart) timingAlignment = Math.max(0, 1 - (activeStart - tti) / activeStart);
    else timingAlignment = Math.max(0, 1 - (tti - activeEnd) / 500);

    const slashReach = slash.range?.maxReach ?? 0;
    const distanceAlignment = threat.distanceToSelf <= slashReach
        ? 1.0 : Math.max(0, 1 - (threat.distanceToSelf - slashReach) / 1.0);

    let score = this.tuning.projectileDefense.cutBase ?? 0.55;
    score *= timingAlignment;
    score *= distanceAlignment;
    score *= this.combatPosture.attackMultiplier;  // 斩是主动动作
    score *= 1.1;  // cut 比 dodge 多一份奖励感
    return Math.max(0, Math.min(0.95, score));
}
```

  1. 玩家扔 dagger → AI 能 dodge（在 timeToImpact 窗口内 dodge 分最高）
  2. AI 有 slash 招 + cuttable 的 projectile → AI 能 cut（timing alignment 好时 cut 分 > dodge）
  3. 石头 cuttable=false → AI 只 dodge 不尝试 cut

#### Step 8：Cut 成功 Buff（可选）

- **验收**：AI 成功斩落 → 移动速度临时提升

### 7.3 风险控制

| 风险 | 防护 |
|------|------|
| ProjectileDefs 参数和原 ThrowComponent 硬编码不一致 | 原封不动搬，Step 2 验收对比飞行轨迹

| dodge/cut 分数和现有 attack 同池竞争时打不过 positioning | score 设计按威胁度拉开；极端情况 threat 很紧急时 0.6+ 分压过 positioning 0.35 |
