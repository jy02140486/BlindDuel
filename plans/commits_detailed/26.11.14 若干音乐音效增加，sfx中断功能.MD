# 1. High-Level Summary (TL;DR)

> **Impact: Medium** — A working-session commit touching the **audio pipeline**, **AI diagnostics**, **content data**, and **debug flags** for the BlindDuel game. No core gameplay algorithms were rewritten, but a few changes alter runtime behaviour (interruptible swing SFX, higher AI aggression) and one ⚠️ debug flag was left **enabled**.

**Key Changes**

- ✨ **New "interruptible SFX" mechanism** — weapon-swing sounds are now cut off the moment a character leaves its attack state, via a new `stop_sfx` animation-bus event (`CombatCharacter.enterState` → `AudioManager._stopInterruptibleFor`).
- ✨ **New audio content** — tavern hall BGM (`tavern_hall_music`), plus `whip_crack` & `wagon_drive` SFX wired into the EP1 ending cutscene.
- 🔍 **Heavy AI/combat diagnostics instrumentation** — logs now carry `id`, `tick`, self/previous state, state-held duration, and opponent attack elapsed time.
- ✨ **Character state bookkeeping** — `CharacterBase.enterState()` now records `prevStateName`, `_prevStateHeldMs`, `_stateEnteredAtMs` to feed those diagnostics.
- ⚠️ **Two behaviour-altering tweaks** — `ThrowComponent.DEBUG_INFINITE_AMMO` flipped to `true`, and tavern-night AI `baseAggression` raised `0.25 → 1.0`.
- 📄 **Docs / housekeeping** — `plans/HandOff.MD` fully rewritten to a trail-marker bug investigation, new `.trae` skill added, licenses updated, and a **2,529-line backup copy of `AIController.js` committed into the source tree**.

# 3. Detailed Change Analysis

## 3.1 🎵 Audio System — Interruptible Weapon SFX

**Components:** `AudioManager.js`, `SfxResolver.js`, `sfx_map.json`, `CombatCharacter.js`

**What Changed**

1. **Schema extension — `sfx_map.json`**: six swing rules gained a new `"interruptible": true` flag. The flag is opt-in (`=== true`), so every pre-existing rule keeps its old behaviour.
2. **Resolver pass-through** (`scripts/Systems/Audio/SfxResolver.js`): the direct-mode branch now returns `interruptible` alongside `audioId`/`options`.
   > ⚠️ Note: the `surface` and `impact` resolution paths (`#resolveSurface`, `#entryToResult`) still **do not** emit `interruptible` — the feature is currently direct-mode only.
3. **Manager bookkeeping** (`scripts/Systems/AudioManager.js`): a new `this._interruptibleBySource = new Map()` tracks `source → audioId`. On a semantic event whose rule is interruptible, the pair is recorded; `detachScene()` clears the map to avoid leaking across scenes.
4. **New bus command** `stop_sfx`: `wireAnimationEventBus()` short-circuits on `payload.type === "stop_sfx"` and calls the new `_stopInterruptibleFor(payload.source)`, which looks up and stops the tracked sound.
5. **Producer** (`scripts/Enties/CombatCharacter.js`): when a state transition leaves a previously *attack-active* state, `enterState()` dispatches `stop_sfx` with `source: this`, right beside the existing `this.trailRenderer?.hide()`.

**Interruptible rule table** (`Data/Audio/sfx_map.json`)

| Semantic event | audioId | `interruptible` | Effect |
|---|---|---|---|
| `swing_light` | `swing_light` | ✅ `true` *(new)* | Cut off when attack state ends |
| `swing_sword_light` | `swing_sword_light` | ✅ `true` *(new)* | Cut off when attack state ends |
| `swing_heavy` | `swing_heavy` | ✅ `true` *(new)* | Cut off when attack state ends |
| `swing_thrust` | `swing_thrust` | ✅ `true` *(new)* | Cut off when attack state ends |
| `swing_metal_slide` | `swing_metal_slide` | ✅ `true` *(new)* | Cut off when attack state ends |
| `footstep_wood`, `footstep_rabble`, `duvet_rustle`, `body_collapse`, `die_collapse`, `on_cloaked`, `off_cloaked`, `on_draw_sheath` | — | ⬜ absent → `false` | Unchanged (ring out fully) |

**Snippet**

```js
// scripts/Systems/AudioManager.js
_stopInterruptibleFor(source) {
    if (!source) return;
    const id = this._interruptibleBySource.get(source);
    if (!id) return;
    this._interruptibleBySource.delete(source);
    this.stop(id);
}
```

## 3.2 🧍 Character State Tracking (`scripts/Enties/CharacterBase.js`)

**What Changed**

- `enterState()` now records the **previous** state name and how long it was held, and stamps the entry timestamp of the new state:
  - `this.prevStateName = prevStateName`
  - `this._prevStateHeldMs = (now - _stateEnteredAtMs) ?? 0`
  - `this._stateEnteredAtMs = performance.now()`
- `pushCommand()` now **logs dropped commands** instead of silently ignoring them:
  ```js
  console.log(`[CharCmd] DROPPED id=${this.id} state=${this.currentStateName ?? "?"} cmd=${command} t=${performance.now().toFixed(0)}`);
  ```

**New state fields**

| Field | Type | Meaning | Consumed by |
|---|---|---|---|
| `prevStateName` | `string` | State before the latest transition | `AIController` combat log |
| `_prevStateHeldMs` | `number` | How long the previous state lasted (ms) | `AIController` combat log |
| `_stateEnteredAtMs` | `number` | `performance.now()` at state entry | `AIController` self-state duration |

> The `_stateEnteredAtMs` field is read by `AIController` as a **public-ish** underscore member — acceptable within the codebase but worth confirming it is intended as a cross-class contract.

## 3.3 🤖 AI Diagnostics (`scripts/Systems/AI/AIController.js`)

**What Changed**

- `fixedUpdate(dtMs = 0, tickCount = null)` now accepts the **tick counter** (aligned with `CharacterBase`, `PlayerController`, `CombatSystem`, `BattleMode`, which already pass `tickCount`) and stores it as `this._lastTick`.
- All four diagnostic log sites now prefix with **entity identity + tick** so multi-entity logs can be correlated:

| Log site | New fields added |
|---|---|
| `[AI-Diag] COMBAT:` | `id`, `tick`, `selfState(...dur=..ms)`, `prev(...held=..ms)`, `oppAtk(...elapsed=..ms)` |
| `[AI-Diag] dist=…` (action choice) | `id`, `tick`, `self=stateName@normTime`, `stamina` |
| `[AI-Diag] dodgeGate REJECT` | `id` |
| `[Phase0]` | `id` |

- The opponent-attack elapsed time is now computed from animation normalised time: `oppNorm * (ap.timing?.totalMs ?? 0)`.

> ℹ️ `AIController` also has a stale comment above the "failure outcome" block (`// 判定为「失败」的 combat outcome`), and the file now carries an unformatted extra blank line — cosmetic only.

# 4. Impact & Risk Assessment

## 4.1 ⚠️ Breaking / Behaviour-Changing

| Item | Severity | Detail |
|---|---|---|
| `ThrowComponent.DEBUG_INFINITE_AMMO = true` | 🔴 **High** | Throws become unlimited and free; AI can spam projectiles. **Must be reverted to `false` before acceptance.** |
| `ep1_tavern_hall_night.json` → `baseAggression: 1.0` | 🟠 Medium | 4× aggression. May break night-tavern balance / make the fight unlosable-or-unwinnable. Verify difficulty curve. |
| `AudioManager.stop(id)` is **global by audioId** | 🟠 Medium | `stop()` stops *all* pooled instances of that clip. If two characters swing simultaneously, one leaving its attack state cuts the other's sound too. Consider per-instance handles instead of audioId. |
| `_interruptibleBySource` holds a **strong reference** to the source object | 🟡 Low | A disposed character that never dispatches `stop_sfx` stays referenced. `detachScene()` clears it, but mid-scene disposal may leak. |
| Callback rename `battle_on_ending_black` → `ending_on_black` | 🟡 Low | ✅ Matches current `ExploreMode` registration. Any *other* sequence still referencing the old name would only warn. |
| `sfx_map.json` schema addition | 🟢 Low | Additive & opt-in; old maps keep working. `SfxResolver` still returns `interruptible` for every direct rule (default `false`). |
| `AIController.fixedUpdate(dtMs, tickCount)` | 🟢 Low | Backward compatible; `BattleMode` already forwards `tickCount`. |
